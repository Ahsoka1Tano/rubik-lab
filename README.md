# Rubik Lab

Браузерная лаборатория для экспериментов с кубиком Рубика 3×3. Поворачивайте грани, изучайте перестановки и проверяйте свои алгоритмы в Python.

[Открыть Rubik Lab на GitHub Pages](https://ahsoka1tano.github.io/rubik-lab/)

## Локальный запуск

Нужны Node.js 22.12+ и pnpm.

```sh
pnpm install
pnpm dev
```

Откройте адрес, который выведет Vite. Для проверки сборки используйте `pnpm build` и `pnpm preview`. Сборка в `dist/` статическая. Для GitHub Pages в подпапке репозитория укажите её явно, например `pnpm build --base=/rubik-lab/`.

Pyodide и Monaco загружаются с того же адреса, что и приложение. Подготовка сборки копирует файлы Python из установленного пакета Pyodide.

## Рабочая область

- Перетаскивайте сцену левой кнопкой мыши, чтобы повернуть камеру. Колёсико меняет масштаб. Кнопка с прицелом возвращает исходный ракурс.
- Панель слева содержит перемешивание, сброс, Undo/Redo и историю. Кнопки граней под кубиком поддерживают обычный, обратный и двойной поворот.
- Редактор можно перетащить за заголовок, изменить размер за нижний правый угол, свернуть и развернуть. Вкладки сохраняются в этом браузере. Каждая вкладка запускается как отдельный скрипт.
- `Run` или `Ctrl+Enter` запускает текущую вкладку. `Stop` останавливает Python и оставшуюся анимацию. Кубик сразу показывает итог уже принятых ходов.
- `Speed` регулирует скорость поворотов. Консоль показывает `print()`, stderr и traceback. Редактор отмечает строку ошибки, пока исходный текст совпадает с запущенным.

## Python API

| Команда | Результат |
| --- | --- |
| `move("R")`, `move("R U R' U'")`, `cube.move("F2")` | Применяет один или несколько ходов. Допустимые грани `U R F D L B`, суффиксы `'` и `2`. Четверть оборота идёт по часовой стрелке при взгляде прямо на грань. |
| `cube.get_state()` | Возвращает новый словарь Python с шестью ключами `U R F D L B`. Значение каждого ключа — строка из девяти букв в порядке строк сверху вниз и слева направо при взгляде прямо на грань. |
| `cube.is_solved()` | Возвращает `bool` для текущего логического состояния. |
| `cube.reset()` | Восстанавливает собранное состояние и очищает историю. |
| `cube.scramble()` | Применяет 25 случайных допустимых ходов к текущему состоянию и возвращает их нотацию. |

Буква наклейки соответствует её грани в собранном кубике. `U` — белая, `R` — красная, `F` — зелёная, `D` — жёлтая, `L` — оранжевая, `B` — синяя. Для боковых граней сверху находится `U`. На `U` верхняя строка примыкает к `B`, на `D` — к `F`.

```python
before = cube.get_state()
for _ in range(4):
    move("R")
print(cube.get_state() == before)  # True, даже после перемешивания
```

Состояние внутри Python обновляется сразу. В интерфейсе каждый принятый ход получает кадр с точными начальным и конечным состояниями. Кубик воспроизводит их в порядке поступления. Код исполняется в отдельном Worker, а UI блокирует другие операции с кубиком до завершения запуска и очереди. После ошибки ранее принятые ходы остаются в истории.

## Тесты

```sh
pnpm test
pnpm typecheck
pnpm build
```

Vitest проверяет все 18 ходов, обратимость длинных последовательностей, паритет и ориентацию деталей, историю и совпадение позиций и нормалей Three.js с математической моделью при завершении анимаций.

## Наставник и границы текущей версии

В окне наставника можно загрузить учебный контекст `.txt` или `.json` (до 256 КБ). Для подключения будущего сервера установите `VITE_MENTOR_ENDPOINT=/api/mentor` при сборке. Сервер должен отвечать на `POST` того же origin.

- Запрос имеет вид `{ messages: [{ role, content }], context: { script?, error?, cube?, moves?, lesson? } }`. В `context` входят только выбранные пользователем поля. `lesson` содержит `name`, `format` и `content`.
- Успешный ответ имеет вид `{ reply: "..." }`. Серверный обработчик для OpenAI API можно добавить отдельно. Ключ API хранится только на сервере.
- Наставник отключён по умолчанию. Ожидание каждой анимации из Python и пошаговая отладка оставлены для следующих версий.
- Вкладки сохраняются локально, а состояние кубика и история сбрасываются при перезагрузке страницы. Для 3D нужен браузер с WebGL 2.
- Один запуск принимает до 10 000 операций с кубиком и до 2 000 строк вывода. Консоль хранит 600 последних записей. Для редакторских вкладок доступна стандартная библиотека из поставки Pyodide, локальные вкладки запускаются по отдельности.
